# まなびチャンピオンズ

学びクエストのQRから育てたチームを読み込み、1台で2人対戦できます。

- 自分のQR画像と友だちのQRを読み込みます。
- 主人公＋仲間2人、装備4枚。3人の行動を選んでREADY。
- キャラの名前から詳細、ステッカーからメイン変更、仲間画像から入れ替えができます。
- 音は初めOFFです。音の設定からONにできます。
- 元の学びクエストのデータは書き換えません。

別端末同士のオンライン対戦はこの公開版には含まれていません。

## 素材

ゲーム内「素材について」に各音源・画像・フォント・ライブラリの表示があります。ライセンス本文は同じフォルダに同梱しています。
